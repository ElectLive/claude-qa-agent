# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming and respectful, assume good intent, critique ideas rather than people, and help newcomers. QA engineers here work in many languages and time zones. Write clearly and be patient.

**Reporting:** contact the maintainers privately through the email on the maintainer's GitHub profile, or use GitHub's private vulnerability reporting with the title "Conduct report". Reports are handled confidentially. Maintainers may remove content or contributors who break this code.
