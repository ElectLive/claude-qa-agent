## Bug Report

**Summary:** On checkout, the expired code `SUMMER24` is accepted and takes 15% off the order total instead of being rejected.

---

## Steps to Reproduce

1. Sign in as a shopper and add one item (€40.00) to the cart
2. Navigate to https://staging.shop.example.com/checkout
3. Enter `SUMMER24` (expired 2026-09-30) in "Discount code"
4. Click "Apply"
5. Observe: the message "Code SUMMER24 applied" appears and the total drops to €34.00

## Expected Result
The code is rejected with "This code has expired" and the total stays €40.00 (AC-02 of #148).

## Actual Result
`Code SUMMER24 applied` is shown, and the order total becomes `€34.00`. `POST /api/cart/discount` returns `200 {"applied":true,"percent":15}`.
