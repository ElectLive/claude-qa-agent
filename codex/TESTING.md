# Testing the agent on Codex

Codex support is experimental: these steps check what was only verified on Claude Code so far.

## Install a pinned version

```bash
git clone --branch v1.2.0-codex.1 --depth 1 https://github.com/GhassenAZZOUZ/claude-qa-agent.git ~/qa-agent
python ~/qa-agent/scripts/codex.py install /path/to/your-app
```

Using GitLab? Merge `~/qa-agent/codex/config.example.toml` into `~/.codex/config.toml`.

Undo: delete the links `~/.agents/skills/<skill>` and `~/.codex/skills/<skill>` that point into `~/qa-agent`, and the `<!-- qa-agent:begin -->…<!-- qa-agent:end -->` block in your app's `AGENTS.md`.

## Checks, from cheapest to fullest

Run each in Codex from your app's folder. None of 1–4 touches your tracker.

| # | Type | Expected |
|---|---|---|
| 1 | List your skills (`/skills`, or ask "which skills do you have?") | The 28 skills show up, e.g. `integration-tests`, `write-tests`, `requirements-analysis` |
| 2 | `what is the difference between smoke and sanity testing?` | A plain answer: no WAY starts |
| 3 | `integration it` with a small OpenAPI spec | It loads `integration-tests`, shows a resource map and asks you to confirm it before writing anything |
| 4 | `write it "Users can reset their password via an emailed link. The link expires after 1 hour. The page must load fast."` | It shows an R-01…R-04 requirements table and asks for a number for "fast". **No test files yet** |
| 5 | Answer 4's questions | `qa-artifacts/test-cases/<feature>-<date>/` with `Test#NN.{md,feature,steps.ts}`, `.md` files ending with the `🤖 _Generated by DevOps QA Agent — review before acting on this._` footer, `.feature` starting with the `# 🤖 …relying on this test.` header |
| 6 | `qa setup`, then `cd qa-artifacts && npx bddgen && npx playwright test --list` | The generated tests compile |

## What to report (an issue is fine)

- Codex version (`codex --version`) and which checks passed
- For 1: whether skills were found under `~/.agents/skills`, `~/.codex/skills`, or not at all
- For 3–5: how `test-writer` ran: as a Codex sub-agent, or inline from `.claude/agents/test-writer.md`
- Anything that still mentions a Claude-only tool (`Skill tool`, `Agent tool`, `qa-agent:`)
